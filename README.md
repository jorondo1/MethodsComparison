Scripts and data for 
__Taxonomic profilers and their influence on metagenomic diversity analyses__

`/data` contains output csvs from taxonomic profilers
`/scripts/src` all shell scripts used to process the raw samples (taxonomic profiling)
`/scripts/src/MethodsComparison_Pipeline.sh` is the main pipeline
`/scripts/*.R` are the scripts to compile taxonomic profiler output files and generate all manuscript figures and statistical tests
